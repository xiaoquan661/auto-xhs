# 员工机运营执行规则

## 已确认的运营约定

- 用户指定员工机、账号、本次运营目标和要求，审核经理 Agent 生成的计划后下发。
- 每篇笔记默认随机阅读 15–45 秒。
- 每次点赞后随机生成 90–180 秒的冷却时间；再次点赞还需完成至少 2 篇不点赞的浏览。
  页面加载、阅读和内容筛选可能使实际两次点赞的间隔更长。
- 员工 Agent 读取具体笔记与账号人设，生成相关评论，自主提交并回读平台结果。
- 员工机独立完成已接收任务、保存执行记录、回传运营数据。经理控制台汇总结果；
  经理 Agent 在下发完成后结束本轮操作，完成或异常时再处理回执。

## 浏览点赞执行

`home-engagement` 在一次首页会话内执行。两次点赞之间，员工机先完成中间的浏览；
如果当前笔记阅读后冷却时间仍未结束，就在详情页等待。每篇结果包含阅读秒数、点赞结果和等待时间。

账号目录的 `engagement-pacing.json` 保存下次可点赞时间和中间浏览篇数，
由同一账号的串行执行链更新。后续任务继承该状态。点赞尝试失败也保留间隔。

经理自动计划使用 15–45 秒默认阅读区间，并为阅读、点赞间隔及页面操作预留任务时间。
本地任务接口接受最长 120 分钟的首页互动任务；经理请求超时晚于员工执行时限。
任务达到时限时回传已完成数量和 `time_limit`，由回执明确体现部分完成。

## 接入状态

- 浏览、点赞节奏：已接入 Python 引擎、共享业务服务、CLI 和经理自动计划。
- 员工独立运行与数据回传：复用分离进程、员工本地执行及 outbox 回传链。
- 自主评论：员工 Codex 已通过 `wake-task` 接入桌面会话执行链，读取上下文并回传执行结果。
  运行入口和验收范围见 [员工 Agent 唤醒连接](EMPLOYEE-AGENT-WAKE.md)。

规则适用于更新后创建的任务。已经下发的任务继续使用其已保存参数；
部署状态和真实账号验收另行记录。
