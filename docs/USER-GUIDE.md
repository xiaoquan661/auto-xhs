# auto-xhs V1 普通用户操作手册

## 1. 启动

在项目根目录双击 `start-auto-xhs.cmd`。系统会准备本项目运行环境、启动或复用本地 WebUI，然后
打开浏览器访问 `http://127.0.0.1:8765`。关闭启动窗口不会自动关闭已经登记的 Bridge；WebUI
不会替你打开、关闭或切换 Chrome。

## 2. 添加第一个账号

1. 在“添加账号”填写容易识别的本机槽位名，不要填写手机号或密码；
2. 推荐选择“绑定已有 Chrome Profile”，点击“扫描 Profile”并选择目标 Profile；
3. 确认添加后，手动打开这个 Profile，并保持小红书页面开启；
4. 在账号卡片点击“启动 Bridge”，再点击“发起配对”；
5. 把配对信息粘贴到目标 Profile 的扩展弹窗并确认；
6. 点击“检查并确认 UID”，核对昵称和 UID 后记录身份。

账号卡片显示“已就绪”后才能执行任务。V1 最多保留六个常用账号槽位。

## 3. 创建任务

“任务与确认”支持首页浏览、关键词搜索、点赞和收藏。选择账号和任务类型后填写目标；点赞或收藏
还需要当前笔记的 ID 与 XSEC Token。账号离线、身份不一致、达到配额或短时间重复目标时，任务
会停止并给出下一步，不会静默重试。

## 4. 评论和回复

评论和回复必须先保存最终草稿。确认窗口会再次展示账号、UID、目标和完整文本；确认只对当前
草稿版本生效且只能使用一次。若结果为 `RESULT_UNKNOWN`，先到小红书页面人工检查，不能直接重发。

发布笔记、定时发布和私信不属于 V1，WebUI 不提供入口。

## 5. 暂停和设置

- 顶部“暂停全部任务”阻止创建或开始新任务，不会强行中断已经执行到平台的动作；
- 设置页可调整全局并发（1–3）、L1 每小时/每日配额、重复目标时间和失败熔断阈值；
- 账号卡片可启用 Windows 登录时自动恢复该槽位 Bridge；此功能不会启动 Chrome；
- “导出脱敏诊断”把报告保存在本机产品数据目录，适合排查问题时提供给开发者。

## 6. 数据和卸载

账号槽位默认位于 `%USERPROFILE%\.xhs\accounts`，任务和诊断默认位于
`%USERPROFILE%\.xhs\auto-xhs`。删除项目目录不会自动删除这些本地数据。若需要彻底清理，先关闭
WebUI 与 Bridge，确认不再需要历史任务和账号配置后，再由用户手动处理上述两个明确目录。

迁移到另一台电脑时需要重新配对扩展；不要复制配对信息、Cookie 或 Chrome Profile 给他人。
