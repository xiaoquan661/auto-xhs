# 自动多账号小红书运营系统：任务板块产品基线 1.0

> 版本：1.0
> 状态：已确认的产品基线
> 适用范围：本地 WebUI 的任务创建、批量与定时计划、确认区和执行记录
> 说明：`小红书Codex模拟操作清单.md` 仅作为历史能力池，本文件是任务板块后续设计与开发的判断依据。

## 1. 产品目标

任务板块用于把用户的运营目标转换成可追踪、可暂停、可审核的本地任务。

任务板块不直接展示大量底层 CLI 命令，而是以用户能理解的任务模板组织能力。系统内部再把模板拆成账号、目标和动作明确的子任务。

基本原则：

- 只读、分析、本地生成类任务可以直接执行。
- 点赞和收藏允许立即、批量及定时执行，创建任务时完成授权。
- 评论、回复和发布必须进入独立确认区。
- 同一账号的任务串行执行，不同账号最多三个并行。
- 所有执行都必须记录任务状态、结果和失败原因。
- 验证码出现时立即停止并等待人工处理，不提供验证码绕过能力。
- 第一版禁止协同刷量。

## 2. 信息架构

任务板块分为三个区域：

1. **立即任务**：创建后立即进入执行队列。
2. **批量／定时计划**：按目标池、数量和时间规则生成子任务。
3. **确认区**：保存等待人工核对和确认的外发或高影响动作。

执行记录独立展示，不和任务创建表单混在一起。

## 4. 立即任务

立即任务使用六种用户级任务模板。

### 4.1 自动浏览

支持：

- 浏览首页推荐。
- 浏览关注内容。
- 设置浏览时间。
- 设置点开数量。
- 选择图文、视频或不限。

达到时间或数量任一上限即停止。结果展示实际点开数量、标题、作者、阅读时间和停止原因。

### 4.2 搜索与收集

支持：

- 搜索笔记。
- 搜索用户。
- 搜索话题。
- 设置关键词、数量和筛选条件。
- 将结果加入本地候选内容池。

候选内容可以继续用于分析、浏览、点赞和收藏任务。

### 4.3 内容与账号分析

支持：

- 读取笔记详情和评论。
- 生成内容摘要。
- 读取用户主页。
- 观察竞品及同类账号。
- 执行单篇笔记或账号内容复盘。

输入可以来自笔记 ID、用户 ID、搜索结果或候选内容池。

### 4.4 内容创作

支持：

- 生成选题。
- 生成标题。
- 生成正文。
- 人格化改写。
- 生成事实核查清单。
- 提供封面和话题建议。

该任务只生成本地草稿，不直接发布。

### 4.5 数据与状态读取

支持：

- 查看笔记管理状态。
- 查看审核状态。
- 读取通知中心。
- 读取数据看板。
- 检查发布结果。
- 检查账号运行状态。

该任务只读取和整理信息，不修改平台状态。

### 4.6 点赞与收藏

支持：

- 点赞。
- 取消点赞。
- 收藏。
- 取消收藏。

用户现场点击“创建并执行”，即视为对本次账号、目标和动作的明确授权，可以立即执行，不再增加第二次弹窗确认。

## 5. 批量／定时计划

第一版支持以下计划：

- 批量或定时自动浏览。
- 批量搜索和内容收集。
- 关键词、话题及竞品定时监测。
- 批量笔记和账号分析。
- 评论、通知和审核状态监测。
- 定期运营报告。
- 批量生成选题或草稿。
- 批量点赞和收藏。
- 定时点赞和收藏。

创建计划时必须明确：

- 目标账号。
- 目标来源。
- 执行动作。
- 开始时间和结束时间。
- 最大执行数量。
- 每个账号的最大数量。
- 执行间隔。
- 重复目标处理规则。
- 异常时暂停当前账号还是终止整个计划。

用户点击“确认创建计划”，即完成对该固定范围的授权。运行期间不得静默扩大账号、目标、动作、数量或时间范围；范围变化需要修改计划或重新创建。

批量计划拆成账号、目标和动作明确的子任务。每个子任务都保留独立结果。

## 6. 点赞与收藏授权规则

### 6.1 单次任务

- “创建并执行”即为本次授权。
- 执行前读取当前状态。
- 已达到目标状态时记录为“无需重复执行”。
- 未达到目标状态时只执行一次并回读结果。

### 6.2 批量和定时任务

- 创建计划时一次性确认完整范围。
- 执行时不逐条确认。
- 支持暂停、继续和取消尚未开始的子任务。
- 结果未知时不自动重复执行，先等待状态核对。

### 6.3 多账号规则

- 允许多个账号处理不同目标。
- 同一目标默认只分配给一个账号。
- 禁止多个账号对同一篇笔记集中点赞或收藏。
- 禁止多个账号相互给自有内容制造互动。

## 7. 确认区

确认区只保存真正等待用户决策的动作：

- 发布评论。
- 回复评论。
- 正式发布笔记。
- 提交已发布笔记的修改。
- 设置定时发布。
- 关注或取消关注。
- 评论点赞或置顶。
- 修改主页资料和隐私设置。

每张确认卡必须展示：

- 目标账号和当前 UID。
- 目标笔记、用户或评论。
- 最终发送内容。
- 图片、视频和发布设置。
- 动作产生的影响。
- 确认有效时间。

确认后如果账号、目标、正文、素材或发布设置发生变化，原确认失效，必须重新确认。

评论、回复和发布在第一版逐条确认，不支持一键批量通过。

## 8. 执行流程

### 8.1 立即任务

```text
选择任务模板
→ 选择账号并填写参数
→ 点击创建并执行
→ 检查账号连接和当前 UID
→ 执行任务
→ 回读结果
→ 保存执行记录
```

### 8.2 批量／定时计划

```text
选择计划模板
→ 设置账号、目标池、时间和数量
→ 预览将生成的子任务
→ 确认创建计划
→ 到时进入队列
→ 按账号串行执行子任务
→ 汇总计划结果
```

### 8.3 确认任务

```text
生成草稿或待处理动作
→ 进入确认区
→ 展示账号、目标和最终内容
→ 用户确认
→ 再次核对关键内容未变化
→ 执行一次
→ 回读并保存结果
```

## 9. 任务状态

统一使用以下状态：

- 草稿。
- 已计划。
- 排队中。
- 待确认。
- 执行中。
- 执行成功。
- 部分成功。
- 执行失败。
- 需处理。
- 结果待核对。
- 已取消。

状态流转示例：

```text
草稿
→ 已计划 / 排队中 / 待确认
→ 执行中
→ 执行成功 / 部分成功 / 执行失败 / 需处理 / 结果待核对
```

## 10. 阻塞规则

以下情况进入“需处理”：

- 出现验证码。
- 登录失效。
- 当前 UID 与任务账号不一致。
- Bridge 或扩展断开。
- 达到已设置的执行数量上限。
- 页面结构无法识别。

出现验证码时，只提示用户接管，不自动识别或绕过。某个账号被阻塞时，暂停该账号剩余任务；其他正常账号可以继续。

## 11. 并发与去重

- 同一账号严格串行。
- 不同账号最多三个任务并行。
- 执行前读取目标当前状态。
- 已经完成的点赞或收藏不重复执行。
- 同一个子任务只允许存在一个明确终态。
- 结果待核对的状态不能自动当作失败重试。

## 12. 结果展示

立即任务结果至少包含：

- 任务摘要。
- 目标账号。
- 开始和完成时间。
- 最终状态。
- 结构化业务结果。
- 失败原因和建议操作。

批量／定时计划结果至少包含：

- 计划数量。
- 成功数量。
- 无需重复执行数量。
- 失败数量。
- 阻塞数量。
- 未开始数量。
- 每个账号和目标的子任务明细。
- 计划停止原因。

## 13. 不属于任务板块的能力

以下能力放在账号或系统设置中：

- 登录和退出登录。
- UID 检查与记录。
- 账号换号。
- Profile 配对和解除配对。
- Bridge 启动和重启。
- 全局并发和任务配额设置。
- 全局暂停。

这些操作不能由普通运营计划代替授权。

## 14. 明确禁止

- 协同刷量。
- 同一目标由多个账号集中点赞或收藏。
- 多账号相互给自己的内容制造互动。
- 批量发送相同评论、回复或私信。
- 验证码绕过。
- 指纹伪装、代理轮换和反检测。
- 自动举报竞争账号。
- 自动删除笔记、评论或账号数据。

## 15. 1.0 验收标准

- WebUI 能明确区分立即任务、批量／定时计划和确认区。
- 用户看到的是任务模板，不是底层命令列表。
- 单次点赞和收藏由“创建并执行”完成授权。
- 批量及定时点赞、收藏在计划创建时完成固定范围授权。
- 评论、回复和发布必须进入确认区。
- 同一目标不会分配给多个账号进行点赞或收藏。
- 验证码出现时任务进入“需处理”，不会继续执行。
- 每个任务和子任务都有明确状态及执行结果。
- 历史成功结果可以在 WebUI 中查看，而不是只显示结果数量。
- 不修改或同步已安装在 `.codex` 目录中的旧技能副本。
