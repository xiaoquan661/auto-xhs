# 小红书员工源码切换与回退

源码切换单位为完整项目checkout中的经理源码、员工源码、固定入口及布局文件的配套版本。

1. 记录当前Git版本、经理与员工源码版、source-layout及webui-layout的对应关系。
2. 选择已验证的目标Git版本，通过正常分支/发布流程准备完整checkout与依赖环境。
3. 按项目部署规则等待活动任务完成，保存代码和配置位置引用，切换对应程序及入口。
4. 回读CLI帮助、模块与资源路径、服务健康和相关回归；安装后按运营安排恢复任务。
5. 业务配置、账号环境、数据库、inbox/outbox及任务身份沿现有受控位置处理，
   已执行动作通过原任务证据续办。

本轮本机验证见acceptance.json；设备切换与回退结果登记于相应migration变更记录。
