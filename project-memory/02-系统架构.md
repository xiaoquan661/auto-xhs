# 系统架构

## 本地执行链

```text
Agent / CLI / WebUI
→ ApplicationService 与能力、身份、任务服务
→ Python 页面自动化模块
→ 每账号 Bridge → MV3 扩展 → 绑定的 Chrome Profile → 小红书页面
→ 页面回读 → 任务、事件、指标与证据记录 → 结果展示
```

## 跨机器执行链

```text
WebUI 运营任务收件箱 → 经理 Agent → 经理服务
→ SSH / SCP → 员工机 Agent / Executor → 员工机本地应用服务
→ Bridge / Chrome / 平台页面 → 操作记录和证据 → 经理端回收与对账
```

## 源码地图

| 路径 | 查什么 |
| --- | --- |
| `scripts/cli.py` | 命令注册、参数和结构化输出 |
| `scripts/application_service.py` | 共用任务、确认、身份与业务服务 |
| `scripts/xhs/` | 浏览、搜索、评论、消息和发布的页面实现 |
| `scripts/bridge_server.py`、`extension/` | Bridge 和真实浏览器扩展通信 |
| `scripts/manager_service.py` | 经理端任务和协作服务 |
| `scripts/manager_worker_service.py` | 员工端任务执行服务 |
| `scripts/manager_store.py` | 经理端状态存储 |
| `scripts/operations_db.py` | 本地任务、事件和指标存储 |
| `scripts/web_server.py`、`webui/` | API 与界面 |
| `SKILL.md`、`skills/` | Agent 执行路由与边界 |
| `tests/` | 自动化行为证据 |

## 状态理解

账号经过 Profile、扩展、配对、登录和 UID 核验后进入 `READY`。
外部动作按能力规则完成预览或授权，执行后通过页面回读结算。
`RESULT_UNKNOWN` 表示结果仍需对账；再次执行前先确认平台实际状态。
