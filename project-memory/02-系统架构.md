# 系统架构

## 本地执行链

```text
Agent / CLI / WebUI
→ ApplicationService 与能力、身份、任务服务
→ Python 页面自动化模块
→ 每账号 Bridge → MV3 扩展 → 绑定的 Chrome Profile → 小红书页面
→ 页面回读 → 任务、事件、指标与证据记录 → 结果展示
```

## 跨机器执行链

```text
WebUI 运营任务收件箱 → 经理 Agent → 经理服务
→ SSH / SCP → 员工机 Agent / Executor → 员工机本地应用服务
→ Bridge / Chrome / 平台页面 → 操作记录和证据 → 经理端回收与对账
```

## 源码地图

经理 PC023 维护经理实现和五机员工源版本；员工 PC052、PC057、PC065、PC071、PC073
有各自的岗位规则及程序实例定义。模块真实文件位置由根 `source-layout.json` 索引。
完整目录见[经理与员工目录说明](../docs/V020-ROLE-LAYOUT.md)。

| 位置 | 职责 |
| --- | --- |
| PC023/function_packages/xiaohongshu-skills/0.1.0/manager/runtime/scripts | 计划、投递、回收、存储、运营汇总、经理知识 |
| 同经理源版本manager/runtime/webui | 经理控制台与远端员工管理 |
| PC023/worker_packages/xiaohongshu-skills/0.1.0/worker/runtime/scripts | 本机业务服务、CLI和xhs自动化库 |
| 同员工源版本worker/runtime/execution | 员工任务、账号环境、Bridge、进程支撑 |
| 同员工源版本worker/runtime/shared | 共用数据工具、本机应用HTTP接口、路径解析 |
| 同员工源版本worker/extension、skills、prompts | 浏览器扩展、执行技能与回复模板 |
| WorkerStation/Workers/AgentWorkers/<PC编号> | 员工规则、个人偏好、岗位与路径定义 |
| WorkerStation/Workers/ProgramWorkers/instances/<PC编号> | 程序源版本和设备部署关系 |
| 根scripts | 稳定调用和导入入口 |
| 根docs、tests、project-memory | 产品、源码验证与交接基准 |

应用HTTP路由由员工源包共用接口实现；经理HTTP服务包裹经理接口，员工执行服务直接消费本机接口。
经理运营汇总和实时记忆解析分别在经理模块；员工回复使用任务缓存与本机记忆。

## 状态理解

账号经过 Profile、扩展、配对、登录和 UID 核验后进入 `READY`。
外部动作按能力规则完成预览或授权，执行后通过页面回读结算。
`RESULT_UNKNOWN` 表示结果仍需对账；再次执行前先确认平台实际状态。
