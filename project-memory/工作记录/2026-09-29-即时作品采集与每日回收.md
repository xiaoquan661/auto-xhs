# 即时作品采集与每日回收

日期：2026-09-29。

## 结论

数据回收有两个固定入口。运营台账号页的“立即采集并回收”通过经理 Web UI 请求员工机，员工机直接运行本项目 `collect-operations-metrics --source creator_manager` CLI，经理机接收采集结果并更新结果库和运营数据源。每日作品采集由员工机本地调度调用同一固定 CLI，写入 outbox，经理机按既有同步流程导入。两条路径均由程序入口执行。

即时采集按当前机器、账号槽位执行；员工机检查暂停状态，并用槽位执行锁保持同账号串行。已有任务排队时可执行即时采集；账号正在执行时返回顺延。PC071/3-3 从本机成功发布记录确定两篇作品 ID。

## 使用

在数据回收页选择员工机与账号，点击“立即采集并回收”读取当前创作者中心数据；“回收已有回执”导入员工 outbox 中的历史或定时采集回执。
