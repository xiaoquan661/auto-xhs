# 数据回收运营视图

## 目标

让运营者快速查看执行成果和需要关注的记录，控制长列表的页面高度。

## 已确认结论与涉及文件

- 数据回收页展示已回收结果、已完成、需关注、成功率和动作目标/实际汇总。
- 执行结果按时间倒序排列，每页 8 条；支持员工机、账号、日期、状态和中文搜索。
- 行内展示动作、账号、实际/目标、状态和时间，详情弹窗承载逐项结果、业务数据、
  链接和任务信息。实际值为 0 时按 0 展示，缺失值显示破折号。
- 增量记录、运营报告、同步与审计采用独立标签页及分页。同步状态在顶部摘要展示，
  员工机回收详情和归档路径可展开查看。
- 数据回收页隐藏重复的全局集群概况；窄屏保持导航文字完整，表格在容器内横向滚动。
- 页面结构：[index.html](../../webui/index.html)；结果视图与样式：
  [manager-results.js](../../webui/manager-results.js)、
  [manager-results.css](../../webui/manager-results.css)；集成与详情：
  [manager-console.js](../../webui/manager-console.js)。
- 本次沿用经理端现有结果读取、日期筛选和手动回收接口。
