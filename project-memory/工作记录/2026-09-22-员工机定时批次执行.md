# 员工机定时批次执行

- 日期：2026-09-22
- 需求：每日指标拆批后提前投递完整时间表，员工机自行接续后续批次。

## 实现

新每日计划采用 `employee_schedule`，将全部批次请求保存至运营任务的
`batch_requests` 后通过现有 SSH/SFTP 链路下发。账号策略支持北京时间
`daily_policy.batch_start_times`；未指定时按批间隔排期，每批最多浏览15篇。
经理预投递按计划执行时刻检查运营时段，员工执行阶段继续检查实际时段与账号规则。

员工执行服务每10秒检查本地队列及已送达 inbox。每批包含计划时间、结束时间、
批次编号、前批依赖和批间隔。同账号串行；到点仍占用则顺延，前批异常时阻塞后批。
未领取且启动进程已退出的原任务可恢复启动；已有领取证据时保留结果核对。
员工控制台显示批次编号与计划时间。

实机发现PC057状态文件约42MB，频繁读取竞争写锁，启动阶段曾报STATE_BUSY。
状态查询改为读取原子替换后的完整快照，写事务仍加锁；等待时刻的任务不反复写状态。
