# 每日采集与数据落盘路径

日期：2026-10-16

分层手册新增员工 Windows 每日采集入口，沿固定采集程序、员工业务库和 outbox 两路返回经理本地库；原有 24 个模块位置保持，新增入口位于员工列顶部。节点名称采用“定时拉取 outbox”。全部层和数据层的图下直接列出员工业务库、每日作品运行记录、每日通知任务记录、outbox 索引与结果文件，以及经理缓存、按日归档和业务库的绝对路径。

依据：五机 ProgramWorkers instances 的 installed_paths / runtime_material_sources、PC023 manager_manifest 的 manager_state / business_database；员工 daily_creator_collection.py、daily_passive_collection.py、product_store.py、operations_db.py、manager_worker_service.py；经理 manager_service.py 的 collector 与 daily_receipts 归档实现。每日作品约定为启用时北京时间 00:30，通知任务独立配置；本次未修改或回读员工机实时启停。

验证：JavaScript 语法、三章生成、29 个导航目标、12 次层切换、原模块位置保持、路径连通和 34 条路径的几何检查通过；标签未与模块、其他标签或其他路径重叠。已离线渲染检查数据层；浏览器实际布局未验证。原版 HTML 保留。
