# PC073 连接状态同步

日期：2026-10-09。范围：PC073 经理端机器与账号状态回读、运营台快照。

## 结论

PC073 的 SSH 地址 `192.168.110.49` 可连接，员工健康检查返回 `PAUSED`、`healthy=true`；暂停是既有运营配置。经理端曾留下账号清单同步的 SSH 握手超时记录，虽然机器健康状态已更新为 `ssh_state=ONLINE`，账号同步字段仍为 `UNKNOWN/OFFLINE`。运营台将经理机本地 `manager-state.json` 的机器与账号记录组合展示；`manager-operations.db` 存运营业务记录，不保存机器 SSH 连接状态。

机器健康回读包含完整账号槽位时，现在同步写入账号状态并将账号同步标为成功，清除旧错误。机器健康和账号清单刷新使用 `ManagerStore.batch()` 一次提交关联状态，减少 75 MB 经理状态文件的重复读写及锁占用。

- 运营台快照回读同为 `PAUSED / SSH ONLINE / 账号同步 SUCCESS`，账号同步错误为空。
