# 扩展截图

2026-09-16，分支 `codex/extension-screenshot-fix`，扩展版本 1.4.3。

后续最小化修复、当前版本及社区调研见[后台截图兼容性](2026-09-16-后台截图兼容性.md)。

## 结论与来源

旧截图入口 `screenshot_element` 使用 `captureVisibleTab`，manifest 未声明该接口要求的
`activeTab` 或 `<all_urls>` 权限；该接口还会截取窗口活动页。
依据为 `extension/background.js`、`extension/manifest.json` 及
[Chrome tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)。

截图入口复用 `cmdVisualSnapshot`，通过现有 debugger 权限截取选定标签页，保持 `{data}`
Base64 返回格式。视口读取和页面活动提示增加 `injectImmediately`，在页面资源加载期间即可执行。
