# 员工步骤恢复机制

## 实现

固定入口在命令调用前持久化RUNNING状态，结束后记录参数、完成状态与时间。截图、笔记详情读取和推荐列表读取遇到明确页面变化或对应临时超时时，自动恢复一次并保留首轮输出。

相同写入步骤的原参数文件再次调用时，已完成步骤复用结果；RUNNING或NEEDS_RECOVERY保留原结果并交核对。runner监测事件与步骤更新时间，默认300秒无进展保存断点；缺少结束回执或无进展且没有待核对写入时，最多再次启动Agent恢复剩余步骤。事件日志追加保留，异常回执保存step_checkpoint。已手动核对槽位的历史归属疑点单列，不当成当前新身份异常。
