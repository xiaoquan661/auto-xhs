## 实现

- 扩展用目标路由、文档切换、笔记/主页数据与 DOM 判定就绪，不要求资源全部加载完。
  旧文档不能满足新导航；已就绪同篇笔记可在详情读取与评论间复用。主页、搜索重新导航以
  保持采集时效。等待采用有界串行轮询，结束后不留下监听或轮询定时器。
- 固定入口提供 help 和回复合法参数示例，参数错误也落执行与输出文件；短业务输出直接
  返回。领取输出保留授权和任务参数，完整记忆另存文件并给出读取路径，原任务保留。
- Agent 将报障材料原子保存到任务 pending-bugs，外层 runner 使用员工服务配置发布到
  outbox，保留发布回执；业务发送仍为单次调用，沿用结果核对和同账号队列。
- 新增 event-timing.jsonl 的事件接收时间、逐命令 Bridge 耗时、导航就绪方式和 runner
  上下文。新证据可用于区分下一轮的导航、命令与事件间隔。
- 主页数据读取同时接受普通对象和 Vue 的 value/_value 包装；实机确认普通对象形态，
  兼容处理后用户资料、互动统计和笔记列表均能返回。

入口说明见 [员工任务执行入口](../../skills/employee-task-entry.md)。
