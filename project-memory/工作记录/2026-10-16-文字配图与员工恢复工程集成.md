# 文字配图与员工恢复工程集成

## 实现

工程基线采用 main 中的运行入口、业务接口与界面样式精简，同时归集文字配图提交、员工网络恢复、
在途步骤等待、机器串行续接和浏览点赞批次指标识别。源码修改在职责源版本中维护，固定入口沿布局加载。

文字配图固定 CLI 读取原任务、槽位和授权，使用任务标题、正文及话题完成编辑器提交和平台回读。
统一能力登记包含 `submit-text-card`，采用发布类能力的身份绑定、结果验证与重试元数据。
完整回归中发现新增命令与能力表的合同缺口，本次已补齐登记与对应合同断言。

员工批次结算识别 `actual_new_metrics / actual_metrics / actual / metrics / counts`，
按本批目标核对浏览与点赞实际量。网络恢复和任务续接沿原执行关联处理，在途步骤与同机串行
按现有队列合同等待和放行。
