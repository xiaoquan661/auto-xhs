# 经理账号状态同步恢复

现象：PC057与PC071账号最后更新于10:13至10:14，超过30分钟后前端显示状态未知，员工实时健康检查仍全部READY。

原因：manager-sync.log显示10:14:55进入回执回收，10:36:00最后一台结束；webui-startup.log记录manager-background-sync在record_sync_status落盘时os.replace报PermissionError/WinError 5，未捕获异常导致唯一同步线程退出。原线程串行运行账号检查与回执回收，长时间回收也会推迟账号检查。

修复：账号检查与回执回收分别使用后台线程；每轮异常记录日志，并在最多30秒后重试。保留10分钟账号检查、3分钟结果回收配置及30分钟过期阈值。通过6项同步测试，包括回收阻塞时账号检查继续、状态文件异常后下一轮恢复。Ruff通过。

部署：经理WebUI已重启加载，11:06:51日志同时启动两类循环；员工执行服务保持运行。实测经理dashboard-snapshot：7账号均READY且stale=false，PC052更新于11:08，PC057于11:10，PC071于11:11；证据tmp/manager-sync-recovery-snapshot.json。另9项轮询配置回归通过，共15项专项测试通过。
