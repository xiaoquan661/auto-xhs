# 经理批量推进与恢复

日期：2026-09-18。范围：经理普通运营任务与每日计划执行驱动。

## 实现

- 每轮按运营任务、账号动作推进；单账号规划、请求构建或派发异常记录后继续其他账号。
- 临时推进错误保存在 `last_agent_error`，保持任务当前阶段，下轮自动继续。
- 按动作保存当前派发失败原因，动作恢复后清除当前错误，Agent 消息保留诊断历史。
- `PENDING_DISPATCH`、`TRANSFERRED` 使用原任务编号、原请求续投；已接收任务继续等待回执。
- `RESULT_UNKNOWN` 和需对账任务保持待核对，同账号后续动作等待。
- 完成判定按计划动作对应的任务编号核对；失败信息更新保持当前执行阶段。
- 每日计划首次投递和续投均检查接口返回值，失败状态与原因写入 `daily_session`。
