# 通知采集与回收

日期：2026-09-29。

## 结论

通知数据先覆盖“评论和 @”及“新增关注”。运营台“立即采集通知”按所选机器和账号槽位调用员工机固定 CLI，采集结果直接导入经理结果库和运营台数据源。员工机每日通知采集使用相同的两条固定命令，结果写入 outbox，由经理机既有同步流程回收。通知页采集保留平台事件时间、事件标识与历史覆盖状态；历史未翻到末尾时，展示已观察数量与部分覆盖状态。

五台机器的每日通知配置均为北京时间 00:10。PC052、PC057 既有任务保持停用；PC065、PC071、PC073 新建任务也处于停用状态。启用时间由后续运营安排确定。
