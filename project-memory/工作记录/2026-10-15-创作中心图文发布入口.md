# 创作中心图文发布入口

日期：2026-10-15。工程归集：2026-10-16。

## 原因与实现

历史 `PUBLISH_TAB_NOT_FOUND` 来自直接进入发布地址后查找“上传图文”标签，
而实际页面需要先展开“发布笔记”菜单。

小红书图文入口现为：进入创作中心笔记管理页 → 点击可见的“发布笔记” →
选择“上传图文” → 确认图文编辑器。RedNote 沿对应平台的入口维护。
发布技能说明与实现一同归集至员工源包。
