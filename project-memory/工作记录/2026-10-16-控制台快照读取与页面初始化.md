# 控制台快照读取与页面初始化

日期：2026-10-16。范围：经理看板的请求内快照、并发计算和页面脚本加载顺序。

## 实现与来源

- 嵌套 `read_view()` 继续使用当前请求的快照和字段投影；后续独立请求读取最新记录。
- 重叠的看板请求共享正在执行的一次进程池计算，完成后的请求发起新计算。
- 基础 API 脚本与依赖它的页面脚本均按文档顺序延迟执行。

实现来源为 `codex/text-card-publish` 已提交的控制台修复，沿当前 main 的职责源码归集。
测试使用临时经理状态，分别验证快照时点、字段过滤、后续请求更新和并发计算次数。
