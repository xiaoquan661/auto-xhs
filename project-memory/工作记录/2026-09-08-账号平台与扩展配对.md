# 账号平台与扩展配对

## 目标

在经理端明确选择小红书或 RedNote，使账号配置、Bridge 和扩展配对信息使用同一平台。

## 已确认结论与涉及文件

- [manager-account-tools.js](../../webui/manager-account-tools.js) 在新增账号和扩展配对弹窗中
  展示平台选项。新建及导入账号必须选择平台，配对结果显示所用平台。
- 尚未配对或确认身份的槽位支持在初次配对时修正平台；已绑定账号沿用已保存的平台。
- [application_service.py](../../scripts/application_service.py) 接收配对时的平台参数，
  调用 [account_manager.py](../../scripts/account_manager.py) 保存初次配对平台。
  平台发生变化时，已运行的 Bridge 按新平台重启，再生成配对信息。
- [index.html](../../webui/index.html) 更新账号工具脚本资源版本。
- 根因是经理端新增账号表单未传平台，账号服务采用默认的小红书平台，配对包随后沿用该值。
