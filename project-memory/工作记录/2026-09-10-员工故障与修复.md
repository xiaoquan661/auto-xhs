# 员工故障与修复

## 结论

已在现有经理与员工链路接入 DEBUG-01 至 DEBUG-04：员工报障、经理诊断交接、修复包构建与
下发、员工备份安装测试、回滚、安装结果核对、服务验证及验收关闭。
参照此前通过 SSH 核实的 PC055 模式，经理 Agent 在项目分支承担复现和代码修复，服务承担
记录、测试及传输安装。改动保留在当前共享工作区，尚未提交。

## 实现

- `scripts/debug_common.py`：故障分类、任务来源键、数据结构、修复文件范围和实际 pytest。
- `scripts/manager_debug.py`：故障工单、诊断交接单、经理测试、修复目录/ZIP、传输与验收。
- `scripts/worker_debug.py`：员工主动报障、安装备份与测试、自动恢复、安装及回滚回执。
- `manager_worker_service.py` 与 `manager_service.py` 复用既有 outbox、批量 SFTP 下载及
  传输协议；新增 debug_incident、debug_receipt 和 repair_package 类型。
- `employee_task_cli.py report-bug` 从任务文件注入账号和执行身份；员工提示词提供调用入口。
- `manager_cli.py debug`、`/api/v1/manager/debug` 和系统设置「故障与修复」共用服务。
- 使用说明：`docs/DEBUG-WORKFLOW.md`；规则和追踪编号同步至 AGENTS.md、追踪矩阵。
