# 关注博主文案统一

日期：2026-09-09。

## 结论与来源

用户确认运营动作名称为“关注博主”。今日目标、历史统计、运营日报、规划编辑、
下一个运营日、下发模板、动作回执和关注明细统一使用该名称。
内部指标仍为 `friend_request`，执行能力仍为 `follow-user`；关注博主按暖互动机会预算执行，
计数与完成率规则保持兼容。

## 涉及文件

- `webui/employee-panel.js`：共享指标、动作名称、明细、策略及模板。
- `webui/manager-console.js`、`webui/manager-results.js`：指标与回执动作名称。
- `webui/index.html`：相关前端资源版本。
- `scripts/daily_operations_plan.py`、`scripts/daily_operations_runner.py`、
  `scripts/manager_service.py`：计划要求、完成摘要与输入提示。
- `docs/EMPLOYEE-OPERATIONS.md`：运营使用说明。
