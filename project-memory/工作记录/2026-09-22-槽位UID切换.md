# 槽位 UID 切换

日期：2026-09-22

## 用户确认的流程

控制台保留一个“切换账号”入口。用户输入新 UID，系统重新读取当前网页登录身份；一致则更新槽位绑定并记录换号历史，不一致则提示换号失败并保留原绑定。“检查身份”继续比较当前 UID 与绑定 UID，并支持复制当前 UID，局域网环境沿用剪贴板降级复制。
