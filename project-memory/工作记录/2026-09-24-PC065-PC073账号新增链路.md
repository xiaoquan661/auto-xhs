# PC065、PC073 账号新增链路核对

日期：2026-09-24。用户反馈两台新员工机SSH可连，但前端新增账号提示连接中断。

现场核对：PC065的`4-1`和PC073的`5-1`均已在员工机账号清单与经理缓存中创建。两机员工服务与只读`profiles`接口可达；经理WebUI重载后同一新增账号接口的`profiles`动作分别约3.8秒、3.0秒成功。机器缓存回读均为ONLINE/PAUSED。新账号均为BLOCKED：Profile/Bridge未启动、扩展未连接；这是账号接入后待完成的配置，与SSH通断分开。

问题来源：PC065曾在SSH握手阶段超时，经理端短时记为OFFLINE；PC073只读账号生命周期请求曾在读取经理机机器登记时因状态文件锁竞争超时。经理状态文件约数十MB，后台同步并发时锁等待可触发前端失败。`ManagerService.manage_remote_account`改为读取原子落盘快照，`ManagerPolling._init_polling`同样无锁读取设置，避免只读入口占用或等待写锁。经理WebUI已重载。26项相关测试通过，涉及文件Ruff检查通过。

后续：用户在员工机启动各槽位Profile/Bridge并完成扩展配对，之后回读账号READY；PC073的Codex登录仍需在启用Agent任务前完成。账号新增结果已确认，勿重复创建同名槽位。
