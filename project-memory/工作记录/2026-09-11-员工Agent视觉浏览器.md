实现：

- `browser-snapshot` 经扩展指定标签页的 CDP 截图，保存 PNG 及视口元数据；员工提示词要求

- `browser-action` 接收截图元数据及原图像素坐标，支持点击、滚动、输入和按键，返回操作后
  截图。页面切换或视口变化后重新观察。业务提交沿用原业务 CLI 和授权、回读链。
- 扩展 1.4.0 图标角标、页面浮层和 popup 显示调用状态；Bridge 支持 50 MiB 消息。
- `step-progress.json` 保留各步骤输出，失败步骤返回当前步骤的 recovery 建议。普通异常
  观察当前页面；身份异常处理身份，未知结果先核对原动作。消息采集保持任务/巡检安排。
