# 槽位绑定身份执行

日期：2026-09-10。分支：`codex/bound-account-execution`。

## 已确认规则

用户要求日常操作直接开始，使用首次确认的槽位账号绑定。绑定跨任务、进程及服务重启持续有效。
首次绑定、用户手动换号和主动检查身份时读取页面 UID；已知退出、身份不符或换号未完成时暂停业务。

## 实现与来源

- `scripts/cli.py`：互动和发布连接读取本地绑定身份；显式身份读取和退出回读同步本地状态。
- `scripts/application_service.py`：READY 采用有效绑定；业务、采集、回复、记忆核对及发布确认
  使用 `execution_user_id`，`live_user_id` 保留最近页面核验记录，来源由
  `execution_identity_source` 标明。
- `scripts/employee_codex_runner.py`：员工任务使用本地绑定 UID 核对下发身份。
- `webui/app.js`：恢复已绑定账号直接就绪，发布确认使用执行身份。
- PRD、追踪矩阵、根执行规则、认证/互动/发布技能和用户说明同步采用上述规则。
