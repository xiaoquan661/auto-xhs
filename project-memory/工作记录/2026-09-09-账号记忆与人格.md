# 账号记忆与人格

MEMORY-03。分支为 `codex/account-memory-persona`。

## 结论与实现

- 通过 SSH 只读核对 PC055 `memory/resident_short_term.py` 与 `resident_memory_router.py`，
  沿用共享核心、账号长期经验、员工短期记忆、交接与事实回传的分层方式。
- 新增 `scripts/account_memory.py`、`manager_memory.py`、`worker_memory.py`。
  经理和员工各使用自身数据目录中的独立 SQLite 记忆库，账号记忆按平台 UID 隔离。
- 经理配置知识与人格，通过现有任务包保存快照；员工按任务和会话恢复有效上下文。
  人格历史和生效时间可查询，新派发任务使用当前人格，既有任务保留原快照。
- 过程事件及结束结果走既有 outbox；动作事实、交接摘要直接留存，经验建议待审核。
  事件标识用于回传去重，记忆写入异常保留任务结果及待修复状态。
- WebUI 增加账号记忆入口、审核与版本历史，补齐人格字段与历史展示。
  经理 CLI 与员工 JSON 入口支持对应记忆操作。
