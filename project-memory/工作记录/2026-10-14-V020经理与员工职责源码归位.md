# V0.20 经理与员工职责源码归位

## 结论

PC023 经理工作区维护经理业务源包、员工源包和包配套关系；PC052、PC057、PC065、PC071、
PC073 分别具备员工 AGENTS、Personal、Role、manifest 和程序实例定义。

143 个现有 Python 实现和 5 个 PowerShell 脚本已移动到职责目录，扩展、技能、提示词及两端
界面实际归位。根 `scripts/` 保留稳定入口，Python 模块映射共 147 项；两端共用图标归同一来源。
布局与调用说明见 [经理与员工目录](../../docs/V020-ROLE-LAYOUT.md)。

## 职责拆分

- 本机应用 HTTP 路由在 `application_http.py`；经理 Web 服务负责经理路由，员工执行服务直接
  调用本机应用路由。
- 经理运营汇总在 `manager_employee_operations.py`；员工共用模块保存纯日期和回执工具。
- 经理实时记忆由 `ManagerReplyMemoryResolver` 显式注入；员工采用任务缓存和本地记忆。
- 历史评论归属审核属于经理业务，`comment_receipt_review.py` 已移入经理源包。
- 员工 runner 使用本机职责规则和技能的绝对路径。

## 源包与交付

两类职责源包均有 manifest、README、CHANGELOG、ROLLBACK、合同、测试入口与验收记录。
源包标识项目源码组合；既有功能编号和历史版本通过 PC023 配套目录关联。
外部功能目录清单登记 34 个版本、33 个功能编号，使用 task_code/function_id/version 复合定位。

记忆包构建从真实源码解析依赖并复制独立快照；包内来源校验覆盖经理、员工和共用实现。
修复包按照路径映射读取、安装和回滚真实源码，在传输和安装前核对设备目录协议版本。
源码 Release 包含职责目录、加载入口、布局映射、启动 CMD、构建模板、测试和开发资料。
