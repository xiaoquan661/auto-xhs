# 小红书职责与路径映射

## 目标与范围

按 NexaFlow V0.20 的经理机到员工机框架，整理本项目现有目录、源码、功能包和运行材料的职责归属。映射范围为 PC023 经理维护工作区及 PC052、PC057、PC065、PC071、PC073 的安装和运行工作区；目标目录使用架构逻辑区域，落地时对应实际身份、版本和磁盘位置。

## 映射结果

本机快照包含 695 个版本管理文件及 2 个当前新增文件，共 697 个源码与资料路径。148 个脚本结合模块函数、调用者和入口逐项归属：经理业务 24、Worker 业务 74、两端共用能力 19、Worker 执行支撑 27、开发与交付 4。现有 34 个版本包结合 manifest、README 和实际运行入口归属：经理业务 14、Worker 业务 18、两端共用能力 2。

## 需要按职责拆分的重点

- manager_service.py：设备账号、业务目标与计划、任务入口、运输、回收和业务入账按方法边界归属。
- manager_worker_service.py：员工配置、接单、执行、结果回传及版本安装按职责边界归属。
- employee_operations.py：经理运营视图和员工增量观察口径分别归属。
- application_service.py：账号、任务、发布、回复、采集业务保留统一调用门面，内部按业务域组织。
- DATA-03：员工指标采集与报告接口分别归属；MEMORY-03：员工事实记录和经理回收导入分别归属。
- MANAGER-FRONT-01..05：前端功能包共同引用统一 WebUI 源码与部署入口。
- REPLY-01 的两种历史业务以 task_code、function_id 和 version 的完整身份定位。
