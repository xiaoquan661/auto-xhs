# 账号卡片分层与调度入口

日期：2026-09-23

## 用户确认的方案

保留账号卡片，默认显示槽位、员工机、状态及调度、登录、当前任务、人设四项信息。异常原因直接展示。连接、UID、配置同步等信息展开查看；管理信息、检查身份及允许调度开关在常用操作区，其他操作集中在更多操作。

## 实现

webui/manager-console.js 与 console-layout.css。调度设置复用原 management PATCH 接口，保留账号备注，反馈保存中、同步成功、同步待确认及失败。详情与更多操作展开状态按机器和槽位记录，自动刷新后恢复。宽屏三列、常规桌面两列、窄屏单列。

## 验证

三个前端测试文件共8项通过，覆盖卡片分层、展开状态、调度接口目标、备注保留、保存失败及现有导航和管理行为。JavaScript语法检查与git diff --check通过。局域网脚本和样式与本地文件一致；内置浏览器加载7账号并检查了卡片和详情展开截图。真实调度开关未作为测试操作。

## 生效范围

http://192.168.110.165:8765/#accounts，静态文件更新即时生效，刷新页面后加载。业务接口与执行规则沿用当前实现。
