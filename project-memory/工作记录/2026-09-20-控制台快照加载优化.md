# 控制台快照加载优化

2026-09-20，经理控制台首页快照包含大量嵌套记忆记录，性能分析显示深拷贝占主要耗时。

- 首页请求创建独立展示视图，省略首页未使用的memory_context、memory_records、memory_usages，完整记录继续保存在原始存储及详情接口。
- 同一请求的展示视图采用浅层集合副本复用嵌套数据，普通存储读取仍保持原有独立对象语义；下次请求重新读取当前数据。
- 当前实际数据：快照约40.18MB降至9.69MB；同一cProfile流程生成耗时34.7秒降至2.94秒。性能分析包含额外开销。
- 最终版本经理服务实际HTTP请求5.26秒，success=true，返回4个账号。已重载经理服务，员工任务独立运行。
- 75项经理服务、轮询和展示投影回归通过，相关Ruff通过。修改在当前开发分支，仅经理服务加载；员工副本同步另行处理。
- 证据：`tmp/profile_dashboard.py`、`tmp/dashboard-profile.stats`和本轮HTTP输出。
