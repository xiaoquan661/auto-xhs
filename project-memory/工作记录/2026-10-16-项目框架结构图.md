# 架构与使用手册维护

日期：2026-10-16。

## 入口与结构

[架构与使用手册](../../docs/项目框架结构.html)提供通信、数据、代码和操作 FAQ。
[连续流程版](../../docs/项目框架结构-连续流程版.html)按经理、通信、员工三列展示固定模块，
全部、通信和数据共用位置与路由，补充每日采集和数据落盘路径。

两份手册均为包含样式、数据和脚本的单文件 HTML，可由浏览器直接打开。
正文、图示与源码引用随实现版本维护；默认读取顺序由[文档索引](../../docs/README.md)登记。

## 数据与交互维护位置

- `manual-data.graphs / graphDetails`：总体图与分层详图的节点和连线。
- `explanations / nodeResponsibilities`：节点含义、前置条件及输入输出。
- `modulePaths / codeModules`：源码位置、功能、策略及实现说明。
- `nodeParticipation / participation`：经理、员工、程序和人工的参与方式。
- `flowRoutes / flowReferences`：流程路线、证据含义和对应说明。

节点 FAQ 与代码章节共同提供详细解释；搜索、缩放、全屏和返回定位由同文件脚本维护。
通信、状态存储、调度或目录发生变化时，同时核对连线含义和对应 FAQ。
