# 扩展配对信息复制

## 目标

支持经理端通过局域网 HTTP 页面复制扩展配对信息，并清楚反馈复制结果。

## 已确认结论与涉及文件

- 原按钮仅调用 `navigator.clipboard.writeText`，失败后显示手动复制提示。
- [manager-account-tools.js](../../webui/manager-account-tools.js) 现在优先使用剪贴板接口；
  接口不可用或被拒绝时，在当前弹窗中选中完整配对文本并执行兼容复制。
- 成功后按钮显示“已复制配对信息”，按钮下方显示结果。浏览器拦截复制时，保留全部选区，
  提示按 Ctrl+C 完成复制。复制操作沿用当前配对文本。
- [index.html](../../webui/index.html) 更新账号工具脚本资源版本。

  测试页使用模拟配对响应；验证范围为前端复制与粘贴。
