# 员工回执持久化恢复

PC057已完成任务的结果文件存在，但状态落盘因Windows共享读取占用失败，
执行进程退出后被记为AGENT_PROCESS_EXITED，原恢复流程未把完成结果继续写回outbox。

## 实现

- Windows状态文件替换遇PermissionError时短暂重试，最长5秒。
- run_task在取得并规范化执行结果后，先独立保存pending-outcomes回执，再提交任务状态。
- 本地调度及健康检查先恢复待入账回执，再检查退出进程。恢复仅提交原结果、写原任务outbox，
  不调用业务执行器。进程退出造成的未知状态可由已验证的持久化结果收敛。
- outbox完成后把待处理文件归档为.done；写入中断则保留，下轮继续。
- 用户暂停及其他待核对状态沿用既有处理规则；业务本身结果未知仍保持未知。

## 验证与部署

本地员工服务、调度及执行服务64项回归通过；补充退出检测恢复分支后，专项8项通过。

验证业务执行次数保持一次。PC052、PC057、PC071各8项专项测试通过，相关文件同步后重载。
