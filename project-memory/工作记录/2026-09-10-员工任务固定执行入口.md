## 实现

- `scripts/employee_task_cli.py` 提供 claim、invoke、finish 固定入口。
  invoke 读取原生 JSON args，自动注入任务账号，在进程内调用既有 cli.main；保存 stdout、
  stderr、开始结束时间及退出码。长文本、引号和换行通过文件传递。
- `scripts/employee_codex_runner.py` 下发完整入口命令和 JSON 示例，员工直接编辑参数文件、
  调用入口、读取结果；复用已实现的槽位绑定身份逻辑与原生结果文件协议。
- `scripts/manager_worker_async.py` 使用账号级 Agent 锁，按同账号接收顺序排队；
  不同账号独立执行。显式 depends_on_task_ids 等待前置完成，前置未成功时回报阻塞。
  普通业务账号锁继续由 CLI 管理；机器或任务暂停时排队进程退出。
- `scripts/manager_service.py` 评论下发前复用已登记 ACTIVE 人设；缺失时立即提示。
  已下发任务的重入沿用冻结人设，不替换历史任务内容。
