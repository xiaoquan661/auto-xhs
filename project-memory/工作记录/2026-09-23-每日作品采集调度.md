# 每日作品采集调度

用户授权员工机每日自动采集本机账号已发布作品数据，通过outbox交经理回收。时间为北京时间00:30，首轮9月24日。Windows交互用户EDY运行daily_creator_collection.py，StartWhenAvailable开启，错过时在可用登录会话补触发。

脚本从本机账号及daily-creator/config.json读取参与配置，复用暂停和占用判断。当前启用PC052/2-2、PC057/ceshi3与tesssst、PC071/3-2与3-3；xiix及3-1不启用。每日账号固定任务ID进入现有员工Agent队列，同账号忙时排队；采集creator_manager全部作品累计指标，保留真实采集时间与空值，finish写outbox。跳过账号也回传原因。经理沿用180秒回收。

本地10项采集协议及调度测试通过，Ruff通过。部署验证证据：tmp/daily-creator-install-PC052.txt、PC057.txt、PC071.txt。Windows任务Creator-0030独立承担作品指标采集；旧Passive-0010通知任务保持既有状态。三机配置自检与下次触发时间回读属于配置验收，首轮业务采集与经理导入尚待实际触发。
