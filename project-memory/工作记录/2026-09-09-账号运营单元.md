# 账号运营单元

## 目标

管理台以一个账号作为一个运营单元，机器展示账号所属设备。沿用 Mila Control Room 的竖向
导航、缩略卡片和详情模块样式。

## 已确认结论与涉及文件

- 左侧账号单元、全部账号卡片和详情使用机器编号与账号槽位的组合标识。同机多个账号独立
  选择，显示各自昵称、平台、UID、健康状态与所属机器。
- 运营总览的账号卡片同样逐账号展示，卡片点击进入相应账号详情；所属机器的信息显示在卡片内。
- 账号详情包含独立的下一个运营日、今日指标、往日指标、动作链接、评论提醒和私信明细。
  下一运营日匹配当前账号最近的已保存参与计划；刷新后保留选择。
- 规划卡片、日报和下发模板以账号为主标题，机器作为所属信息；参与数量按账号统计。
- 设备工作区继续负责机器管理，账号管理保持已有操作入口和竖向导航。
- RedNote 账号详情根据平台生成主页链接。账号数据在设备暂未返回时仍可展示。
- 涉及 `webui/manager-console.js`、`employee-panel.js`、`manager-planning.js`、
  `index.html`、`control-room.css`、`employee-panel.css` 和两份前端行为测试。
