# Agent 智能回复

日期：2026-09-15

## 当前行为

账号启用回复后，Agent 根据人设、知识、笔记或会话上下文判断并生成回复。
Agent 提交 reply 或 skip；信息不足时自然追问或说明已知范围。
执行链维护账号、渠道、生效时段、事件去重、会话轮次及平台回读。
私信会话由 Agent 持续处理，新消息正常进入事件队列。
生成失败和时段顺延保留待处理状态；未知发送结果关联原任务核对。

## 实现

- 回复服务删除自动/人工类别配置、按类别或事实字段转人工及固定文风检查。
- 应用服务和采集器删除人工会话拦截与转交逻辑，CLI 删除会话恢复入口。
- 对账服务继续匹配原事件出站消息，补正延迟回读。
- 数据库版本 14 移除规则类别字段，原未发送的待处理消息回到 NEW，
  保留已关联任务的发送证据，私信所有权迁移为 CODEX。
- 提示词、Skills、PRD、说明文档及界面状态文字同步当前行为。
