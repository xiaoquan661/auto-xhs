# 行为执行记录

日期：2026-09-15。范围：经理控制台账号详情。

## 实现

- 执行记录按浏览、点赞、收藏、评论、关注、评论回复、私信回复、私信发送、发布、采集分组，
  每组汇总记录结果，按任务轮次展开，最新一轮默认展开。
- 兼容复合任务的平铺行为与嵌套行为；每项采用独立状态，写入成功采用平台回读确认。
- 巡检采集独立读取渠道覆盖及数量，采集与回复分别呈现；缺失数量保持未确认，
  本次采集记录、本轮新发现与每日新增分别说明。
- 入站事件通过本账号事件编号关联昵称、内容与链接。逐项执行归属保留原始回执索引。
- 今日统计表集中展示目标、实际数量与状态，行为明细统一在下方执行记录中查看。
- 来源：webui/employee-panel.js、webui/employee-panel.css、当前经理回执接口。
