# 2026-09-29 公共工具统一

## 范围

第一批代码结构整理限定为三个行为完全一致的公共工具：JSON 文件读写、Unix 时间戳转换和服务启动日志截取。账号流程、经理与员工存储、HTTP 服务及兼容入口保持原有边界。

## 实现

- `scripts/json_io.py` 统一可选 JSON 对象读取和原子写入，账号身份与扩展配对共同调用。
- `scripts/time_utils.py` 统一秒或毫秒 Unix 时间戳到 UTC ISO 时间的转换，评论监控与通知采集共同调用。
- `scripts/process_utils.py` 统一服务启动日志末尾截取，执行服务与 WebUI 生命周期共同调用。
- 原业务模块删除对应的重复私有实现，调用名称和结果结构保持不变。
