# 数据回收账号内容视图

日期：2026-09-16
分支：codex/recovery-business-view

用户确认数据回收按员工机、所属账号、发布内容逐级查看。

## 实现

- 入口展示员工机卡片；点击后仅展示该机器绑定账号，选择账号后展开内容区。
- 切换员工机清空账号选择；账号列表按 machine_id 过滤，自动刷新保留当前选择。
- 发布内容按笔记卡片展示标题、发布时间、作品链接、浏览量、点赞、收藏、评论、转发，
  以及累计指标更新时间。指标来源复用该机器该账号该笔记的最新快照，缺失值为横线。
- 数据详情展示每日记录，发布执行和回执历史可展开。
- 采集数据、运营汇总及日期筛选作用于当前账号；重置日期保持员工机和账号选择。
- 同步状态与历史弹窗保留顶部入口。
