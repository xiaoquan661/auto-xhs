# 评论即时提示回执

## 实现

主动评论在点击前向当前页面注册 MutationObserver，捕获明确的评论成功或失败提示，
保存提示文本、时间、页面地址和本次提交标识。调用方取得结果后清理监听；总等待上限8秒。
已有可见提示不作为本次提交证据。成功返回 confirmation_source=platform_success_notice、
platform_readback 和 platform_receipt，经 CLI、业务适配器及随机评论结果向上保留。

员工执行说明要求直接采用成功提示回执；主动评论提交后不滚动查找自己的评论。
未捕获明确提示时记录 RESULT_UNKNOWN 并结束步骤，保持单次提交。
回复功能定位别人评论的发送前滚动流程保持现状。
