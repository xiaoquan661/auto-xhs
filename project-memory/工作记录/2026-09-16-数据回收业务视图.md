# 数据回收业务视图

日期：2026-09-16
分支：`codex/recovery-business-view`

## 确认范围

用户确认按执行结果、采集数据、运营汇总组织数据回收；同步状态和回执历史作为辅助入口。
执行结果沿用已发布笔记入口，详情展示笔记运营指标，并可展开本任务回执历史。

## 实现

- 采集数据复用 EmployeeOperations 按员工机、账号去重补全的观测数据，补入创作中心笔记快照。
  按评论、私信、新增粉丝、收获点赞、指标快照、采集与回复记录分类，支持类型与内容筛选。
  列表显示内容、用户、处理情况和时间；详情展示来源、指标、完整记录。
- 运营汇总按日期和账号读取既有 daily_metrics，展示八项动作及四项被动指标、缺口和待回复事项。
  详情展示目标、实际、数据状态、当日采集明细及对应执行记录。
- 已保存日报/周报在运营汇总底部折叠展示，保留生成时快照。
- 同步状态与回执历史由顶部入口打开独立弹窗，历史列表独立分页。
- 缺失数量显示未取得，零值保留；新增统计沿用北京时间自然日口径，指标快照标记累计。

## 来源

- `scripts/employee_operations.py`：collection_records、summary。
- `webui/manager-results.js`、`manager-results.css`：采集、汇总、回执历史展示。
- `webui/manager-console.js`、`index.html`：筛选数据、入口和资源版本。
