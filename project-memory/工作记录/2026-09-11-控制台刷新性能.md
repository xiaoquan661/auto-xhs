# 控制台刷新性能

日期：2026-09-11。分支：codex/console-refresh-performance。

## 原因与实现

经理控制台dashboard-snapshot实测9.591秒，响应13,887,651字节。tasks为0.334秒，system/status为0.828秒。
一次快照构建读取12MB经理状态文件44次，目标与运营任务进度重复复制全部回执。剖析期间存在3秒文件锁等待，反映与后台同步竞争；剖析计时包含采样开销，不等同HTTP时延。

ManagerStore新增请求内读取视图：每请求读取文件一次并释放锁，之后的聚合复用一致状态。目标和任务进度复用请求内结果集合；下一请求重新读取当前状态。
HTTP按浏览器Accept-Encoding为大JSON使用gzip传输。前端主快照到达立即渲染，辅助接口随后更新。
