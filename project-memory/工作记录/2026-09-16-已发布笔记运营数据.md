# 已发布笔记运营数据

## 用户确定的口径

数据回收列表以已发布笔记为入口，详情展示创作服务平台“笔记管理”的累计浏览量、点赞、
收藏、评论、转发及采集时间。图文和视频均适用。用户下发更新任务时采集，按北京时间
每天展示最后一次快照，保留历史采集；未采集显示待更新，实际零值显示 0。

## 实现

- `scripts/xhs/creator_metrics.py`：读取真实卡片的 noteId、标题、发布时间及五项计数，
  按指定 ID 筛选。平台卡片顺序为浏览、评论、点赞、收藏、转发；缺失保持空值。
- `collect-operations-metrics --source creator_manager --note-id <ID>`：CLI 默认使用创作中心，
  支持重复指定 ID；复用槽位身份，已在笔记管理时直接读取。RedNote 沿用平台路由。
- 复用 MetricService 时间快照、员工 business_result 和 outbox 回收协议；逐篇采集不产生
  账号累计指标快照。目标笔记未找到或计数缺失返回 partial 与明确 ID。
- 控制台发布详情按机器、账号、笔记 ID 关联回收数据，按北京时间归并每日最新采集。
  数据回收主列表展示发布记录；任务原始数据继续保留在后端。
- `skills/xhs-content-ops/SKILL.md` 登记按任务采集及完整结果回传约定。
