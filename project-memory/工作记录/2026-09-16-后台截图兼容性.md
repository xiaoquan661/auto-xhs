## 社区资料

- [Playwright #41650](https://github.com/microsoft/playwright/issues/41650)，2026-07-05：
  报告者在 Windows Server 2025、Edge 150、CDP 附着已有浏览器时遇到最小化截图超时。
  使用截图前恢复窗口并置前、截图后还原窗口状态的兼容办法。该 issue 本身修复的是初始化
  hook 与首次工具调用之间的竞态，不代表浏览器最小化渲染问题已经修复。
- [Chromium PageHandler](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/content/browser/devtools/protocol/page_handler.cc)：
  源码说明完全隐藏视图的 surface 截图可能因没有呈现帧而停住，与本机获取图像阶段超时一致。
- [Puppeteer #7251](https://github.com/puppeteer/puppeteer/issues/7251)：
  报告截图触发临时 1 像素视口和 resize，报告者反馈 `captureBeyondViewport: false` 可解决
  该复现。这个开关处理截图时的尺寸副作用，不能据此认定能解决所有最小化渲染问题。
- [Microsoft amplifier-browser-bridge](https://github.com/microsoft/amplifier-browser-bridge/blob/main/docs/designs/browser-bridge.md)：
  记录 macOS 下 CDP 最小化截图成功，并将 Windows occlusion 明确列为未测试事项。
  说明平台差异应由实测判断。
