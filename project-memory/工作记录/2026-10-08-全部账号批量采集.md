# 全部账号批量采集

日期：2026-10-08

## 结论

- 数据回收页顶部提供“全部采集作品”“全部采集通知”“全部回收回执”，可直接操作经理端登记的全部账号。
- 点击时固定本轮账号范围；按员工机分组，同机串行，最多三台员工机并行。单项失败后继续其他账号，逐项显示数量、状态和原因。
- 即时采集复用现有固定 CLI 接口，员工返回采集回执后由经理导入数据；通知范围沿用评论/@及新增关注。回执回收每台机器调用一次，支持同步回执证据选项。
- 本轮结束后重新读取经理快照，刷新失败单独提示。批量执行期间需保持页面打开；账号占用、暂停和部分完成状态按现有接口结果显示。
- 基础 API 脚本先加载，再初始化页面模块；页面验证时的初始化依赖错误已修复。

## 来源

- `webui/index.html`：全局入口及脚本加载顺序。
- `webui/manager-bulk-collection.js`：目标快照、分组执行、进度及状态呈现。
- `webui/manager-console.js`、`webui/manager-results.css`：账号范围更新与布局。
- `scripts/manager_service.py`：复用 `collect_creator_now`、`collect_notifications_now`、`collect_results` 接口。
