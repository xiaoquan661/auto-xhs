# 作品采集功能核对

核对日期：2026-10-08，北京时间。

## 当前实现

运营台“立即采集作品”调用 `/api/v1/manager/creator-metrics/collect-now`，经理服务通过 SSH 请求员工 `collect-creator-now`，员工固定 CLI 读取创作者中心后直接返回回执，经理导入结果并同步员工业务库。每日入口在员工本地 00:30 生成采集任务，经 `DirectCreatorMetricsRunner` 调用相同 CLI，完成后写入 outbox。两条入口均由程序执行。

采集前重新导航并等待笔记管理页加载，读取作品 ID、标题、链接以及浏览、评论、点赞、收藏、分享累计值。缺失值保留为空，真实零值保留为 0。同账号执行受槽位锁约束。
