# xiaohongshu-skills 项目记忆库

本库保存项目背景、架构、当前阶段、长期决策和工作交接。Agent 根据任务检索相关笔记，用户可在
Obsidian 中阅读和修改。正式规则、实现和运行结果分别回到 PRD、源码与证据核对。

## 开始阅读

1. [当前状态](03-当前状态.md)：开发现场、文档登记状态和待核对事项。
2. [项目概览](01-项目概览.md)：产品、对象和使用入口。
3. [系统架构](02-系统架构.md)：模块位置和执行链。
4. [决策记录](04-决策记录.md)：已有产品与工程选择。
5. [权威资料索引](05-权威资料索引.md)：正式文档入口。

## 工作区

- [收件箱](收件箱/README.md)：临时资料、想法和待确认问题。
- [工作记录](工作记录/README.md)：任务完成后的结论与验证。
- 模板：[工作记录](模板/工作记录模板.md)、[决策记录](模板/决策记录模板.md)、
  [调研笔记](模板/调研笔记模板.md)。

## 读写方式

开始任务先读首页和当前状态，然后按主题搜索笔记、正式文档及源码。完成后追加一篇工作记录，
并按实际变化更新状态或决策。重复主题优先更新原笔记，历史记录保留当时的日期和证据范围。

笔记至少包含结论、日期、来源和适用范围。测试记录写清命令、结果和覆盖范围；设备记录写清设备、
执行动作及回读结论。来源矛盾时把差异记入当前状态，并在处理具体需求时确定口径。

## 在 Obsidian 中使用

选择“打开文件夹作为仓库”，打开项目根目录 `xiaohongshu-skills`，再打开本页
`project-memory/README.md`。整个项目处于同一个 Vault，记忆库可以直接链接到 `docs/` 和源码。

将本页加入书签；启用核心插件“模板”，将模板文件夹设为 `project-memory/模板`。
本库使用标准 Markdown 相对链接，支持普通编辑器阅读，也能被 Obsidian 反向链接索引。
