# 项目概览

`xiaohongshu-skills` 是使用真实 Chrome Profile、通用 MV3 扩展、Bridge 和 Python 引擎的
多账号小红书运营项目。正式支持目标为 Windows 10/11。

## 入口与职责

| 入口 | 职责 |
| --- | --- |
| WebUI | 配置账号、人设和目标，提交运营任务，处理确认、查看结果与诊断 |
| Agent | 理解目标、读取上下文、规划与派发任务、读取结果并反馈 |
| Python CLI | Agent、自动化调度、测试和高级诊断的标准执行接口 |

## 核心对象

- 账号槽位：运行配置、Profile、Bridge、扩展配对和身份基准的稳定容器。
- 登录身份：通过当前平台 UID 核对槽位与浏览器中的真实账号。
- 任务：保存目标、账号、执行步骤、授权状态、结果和证据。
- 运营目标与人设：按账号维护版本，具体任务关联所用快照。
- 功能包：按功能编号和版本交付运行入口、测试、配置及验收材料。

V1.0 建立热登录、多账号与受控互动基线；V1.5 扩展经理/员工协作、发布和消息；
V2.0 增加评论与私信上下文、智能回复决策及回读。

## 开发与执行

```powershell
uv sync
uv run ruff check .
uv run pytest
python scripts/cli.py --help
```

账号命令形式为 `python scripts/cli.py --account <slot> <subcommand>`。
涉及小红书业务操作时先读取对应 Skill，并按能力规则处理账号、预览、确认和回读。
